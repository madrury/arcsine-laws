# Simple Coinflip Games

Simulations and plots for a talk at the PuPPy Python group on the properties of a simple coinflip game, i.e., a simple random walk. Covers the central limit theorem and the Lévy arcine laws.

Inspired by a quote from Feller's textbook:

> We shall encounter theoretical conclusions which not only are unexpected but
> actually come as a shock to intuition and common sense.

## Setup

    uv sync
    uv run pytest
    uv run jupyter notebook
    # or, if you're fancy...
    uv run jupyter lab notebooks/
